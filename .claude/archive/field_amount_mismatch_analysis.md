### 方案3: 使用板块标题的格式特征

板块标题通常具有特定格式：
- 字体较大
- 居左对齐（X坐标小）
- 独立成行（Y坐标与其他文本有明显间隔）

```python
def is_section_title(text, x_coord, nearby_texts):
    """判断是否是板块标题"""
    # 1. X坐标应该在左侧（< 500）
    if x_coord > 500:
        return False

    # 2. 文本应该简短（< 10个字符）
    if len(text) > 10:
        return False

    # 3. 应该独立成行（下一行Y坐标差距大）
    if nearby_texts and abs(nearby_texts[0][1] - current_y) < 50:
        return False

    return True
```

## 技术要点

### 关键词匹配的挑战
1. **模糊匹配风险**: 短关键词容易误匹配长文本
2. **重复关键词**: 同一关键词可能出现多次（如"退款"）
3. **OCR识别误差**: 可能识别为相似文字

### 板块切分的挑战
1. **依赖关键词准确性**: 一个错误会级联影响所有板块
2. **Y坐标偏移**: OFFSET=80px是否适用所有情况
3. **板块高度验证**: 当前缺少合理性检查
