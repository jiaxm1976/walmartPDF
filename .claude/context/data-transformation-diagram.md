## 🎯 关键转换逻辑详解

### 1️⃣ 字段名规范化 (normalize_field_name)

```python
输入: "总计："              输出: "总计"            (去除标点)
输入: "WFS运输税退款"       输出: "WFS 运输税退款"   (规范化空格)
输入: "其他税款（费用）"    输出: "其他税款"        (去除括号)
输入: "T沃尔玛出资的节余总额" 输出: "T沃尔玛出资的节余" (同义词映射)
```

### 2️⃣ 核心字段判断 (is_core_field)

```python
is_core_field('sales', '产品价格')    → True   (100%出现率)
is_core_field('sales', '运输')        → True   (100%出现率)
is_core_field('sales', '其他税款')    → False  (16.7%出现率 < 30%)
```

### 3️⃣ 低频字段汇总 (other_total计算)

```python
# Sales板块示例
低频字段列表:
- "其他税款": "5.00"
- "临时调整": "-2.50"
- "未知费用": "3.00"

计算过程:
other_total = 5.00 + (-2.50) + 3.00 = 5.50
```

### 4️⃣ 类型转换 (parse_amount)

```python
"1355.89"     → Decimal('1355.89')
"-195.44"     → Decimal('-195.44')
"0.00"        → Decimal('0.00')
"invalid"     → Decimal('0.00')  (带日志警告)
```

## 📊 完整示例：一个PDF的数据转换

### 输入：PDF解析结果 (JSON)

```json
{
  "header": {
    "开始日期": "2024年12月6日",
    "结束日期": "2025年1月11日",
    "期初余额": "-122.56"
  },
  "sales": {
    "产品价格": "1355.89",
    "运输": "13.98",
    "其他税款（费用）": "5.00"
  }
}
```

### 处理过程

```python
# 1. 规范化
normalized_sales = {
    "产品价格": "1355.89",
    "运输": "13.98",
    "其他税款": "5.00"  # 去除括号
}

# 2. 分类
核心字段: {"产品价格": "1355.89", "运输": "13.98"}
低频字段: {"其他税款": "5.00"}

# 3. 转换
processed_sales = {
    'product_price': Decimal('1355.89'),
    'shipping': Decimal('13.98'),
    'net_commission': Decimal('0.00'),  # 填充默认值
    ...
    'other_total': Decimal('5.00')  # 低频字段汇总
}
```

### 输出：数据库记录

```sql
-- statement_headers 表
INSERT INTO statement_headers (
    pdf_file_id, start_date, end_date, opening_balance
) VALUES (
    1, '2024-12-06', '2025-01-11', -122.56
);

-- sales_details 表
INSERT INTO sales_details (
    pdf_file_id, product_price, shipping, net_commission, ..., other_total
) VALUES (
    1, 1355.89, 13.98, 0.00, ..., 5.00
);
```

## 💡 核心设计优势

### 1. 灵活性
```
新字段出现 → 自动识别为低频字段 → 汇总到other_total
无需修改Schema，无需代码更新
```

### 2. 数据完整性
```
所有字段的金额都被保存:
- 核心字段 → 独立列存储
- 低频字段 → other_total汇总
总金额 = 核心字段总和 + other_total
```

### 3. 查询效率
```sql
-- 查询核心字段：直接访问列
SELECT product_price, shipping FROM sales_details WHERE pdf_file_id = 1;

-- 查询总金额：包含other_total
SELECT product_price + shipping + ... + other_total AS total_amount
FROM sales_details WHERE pdf_file_id = 1;
```

### 4. 扩展性
```
未来需要将低频字段升级为核心字段:
1. 更新 core_fields.py 配置
2. 运行数据库迁移脚本
3. 重新解析历史PDF（可选）
```
