API v2 参考 — 接口与调用说明

位置：/api/v2/。本文档包含主要端点、请求/响应示例、curl 与 JS 调用示例，以及鉴权与错误处理建议。基于当前代码实现（见 backend/app/api/v2/routes.py 与 backend/app/schemas/v2.py）。

概览

  • GET /api/v2/health — 健康检查
  • POST /api/v2/parse — 解析 PDF 返回 ParseResult（仅预览，不写库）
  • POST /api/v2/import — 将解析结果写入数据库，返回 ImportResult
  • GET /api/v2/statements — 列表（分页）
  • GET /api/v2/statements/{id} — 详情

POST /api/v2/parse

功能

解析指定 PDF，返回解析的结构化预览。适用于前端预览和人工校验，不会写入数据库。

请求（JSON）

{
  "pdf_path": "backend/tests/test_data/sample_statement.pdf",
  "output_dir": null
}

成功响应（ParseResult）

{
  "status": "SUCCESS",
  "success": true,
  "data": {
    "sections": {
      "header": [{"field": "统计区间", "value": "2025-12-01 - 2025-12-31"}],
      "right_section": [{"field": "待付款金额", "value": "$1,234.56", "raw": "$1,234.56"}]
    },
    "metadata": {"source": "parser"}
  },
  "right_section_raw": {"待付款金额": "$1,234.56"},
  "error": null,
  "process_time": 0.45
}

状态码

HTTP 含义
200 解析成功或返回解析结构（包含 status 字段可为 ERROR）
4xx / 5xx 请求无效或服务器内部错误

curl 调用示例

curl -X POST http://localhost:8000/api/v2/parse \
  -H "Content-Type: application/json" \
  -d '{"pdf_path":"backend/tests/test_data/sample_statement.pdf","output_dir":null}'

Axios 示例

import axios from 'axios';
const res = await axios.post('/api/v2/parse', {pdf_path, output_dir: null});
if(res.data?.success){
  // 使用 res.data.data 渲染预览
}

POST /api/v2/import

功能

把解析结果写入数据库。后端会尝试将解析字典验证为 JGData（Pydantic）；验证成功时优先调用 import_from_model 并返回 ImportResult，验证失败则回退到兼容的 import_jg_data 路径。

请求（JSON）

{ "pdf_path": "backend/tests/test_data/sample_statement.pdf" }

成功响应（ImportResult）

{ "success": true, "statement_id": 123, "message": "imported" }

注意

  • 此端点会写数据库，仅在开发/测试环境或有权限时调用。
  • 若想先预览，请先调用 /parse，经人工确认后再调用 /import。

curl 调用示例

curl -X POST http://localhost:8000/api/v2/import \
  -H "Content-Type: application/json" \
  -d '{"pdf_path":"backend/tests/test_data/sample_statement.pdf"}'

Axios 示例

const res = await axios.post('/api/v2/import', { pdf_path });
if(res.data?.success){
  console.log('imported id', res.data.statement_id);
} else {
  console.error(res.data.message);
}

鉴权

项目支持 JWT 鉴权。若生产启用，请在请求头添加：

Authorization: Bearer <JWT>

示例脚本：scripts/api_examples.sh 中预留了 TOKEN 变量用于本地演示。

错误处理与常见问题

  • ParseResult.error: 若解析失败，/parse 会返回 status: "ERROR" 且 error 字段包含错误信息。
  • ImportResult.message: /import 的失败信息会放在 message 字段中。
  • 后端会记录日志；前端展示时应在 UI 上提供重试与导出日志按钮以便排查。
