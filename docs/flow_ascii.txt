关键数据结构（简洁）
- ParseResult（脚本期望）:
  - status: "SUCCESS" | "ERROR"
  - data: { left_section: JGStructuredData, right_section: dict }
  - error, process_time
- JGStructuredData:
  - sections: Dict[str, List[Item]]
    - Item: { field: str, value: Any, raw?: str }
  - metadata: Dict（可选）
- 右侧流程：
  - RightSectionOCR 输出: { "payment_details": {...} }
  - RightSectionProcessor 输出: 清洗字典 → 转为 sections['right_section'] 列表项

关键耦合点（一句话）
- 脚本直接读 importer.conn、解析返回格式不统一、右侧处理有重复路径 —— 都应在服务层统一封装。

立即可做（优先项）
- 在 StructuredDataImporter 中添加 exists(pdf_name) -> bool 并替换脚本中直接 SQL 检查，快速降低耦合。
