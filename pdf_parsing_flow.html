详细流程说明

1. PDF上传

用户通过前端界面上传PDF文件，系统接收并存储文件到临时目录。

2. OCR文本识别

使用OCR技术识别PDF中的文本内容，获取每个文本块的以下信息：

  • 文本内容
  • 坐标位置（X、Y坐标）
  • 宽度和高度
  • 字体大小和颜色
识别定位方法：通过OCR引擎获取每个文本块的精确坐标，为后续文本行合并和板块定位提供基础数据。

3. 文本预处理

对OCR识别的文本进行标准化处理，消除格式差异：

  • 全角转半角：将全角字符（如“１２３”）转换为半角字符（如“123”）
  • 空格清除：移除所有空格（包括中间空格和前后空格）
  • 大小写转换：将所有字母转换为大写
def preprocess_text(text: str) -> str: """文本预处理（统一处理）.""" text = full_to_half(text) # 全角转半角 text = remove_all_spaces(text) # 清除所有空格 text = to_upper_case(text) # 小写转大写 return text

4. 文本行合并与定位

根据Y坐标合并相邻文本块，形成完整文本行：

  • 计算每个文本块的Y坐标范围
  • 合并Y坐标差值在阈值范围内的文本块
  • 按X坐标排序，形成完整文本行
关键技术：Y坐标阈值合并算法，确保同一行文本正确合并，为后续字段提取提供准确的文本行数据。

5. 板块识别与定位

识别文档中的各个板块（如销售模块、调整模块等）：

  • 使用正则表达式匹配板块标题（如"销售"、"调整"、"WFS"等）
  • 基于板块标题定位每个板块的起始和结束位置
  • 处理板块内的所有文本行
SECTION_KEYWORDS = { "sales": [r"销售", r"SALES"], "adjustment": [r"调整", r"ADJUSTMENT"], "wfs": [r"WFS", r"世界FS"], # 其他板块关键词... }

6. 字段提取与键名匹配

从每个板块中提取字段和对应金额：

  • 键名变体处理：使用同义词映射表处理同一字段的不同表述
  • 正则表达式提取：使用正则表达式匹配金额格式
  • 多模式匹配：支持多种字段格式（如"标签 金额"、"标签:金额"等）

7. 数据验证与计算

验证提取的数据准确性：

  • 总计校验：计算子字段总和与总计字段对比（允许±0.01误差）
  • 必填字段检查：确保关键字段不为空
  • 数据类型验证：确保金额为有效数字
def _validate_total(self, section_data: Dict[str, Decimal], section_name: str) -> Dict[str, Any]: # 定义各板块需要参与计算的字段 section_fields = { "sales": ["product_price", "shipping", "wfs_shipping_refund", "net_tax_collected", "net_commission", "withholding_tax", "wfs_shipping_tax_refund", "walmart_funded_savings"], # 其他板块字段定义... } # 计算子字段总和并与总计对比 # ...

8. 数据入库

将验证通过的数据存储到数据库：

  • 转换为数据库兼容格式
  • 插入到对应的数据库表中
  • 记录操作日志

关键技术点总结

识别定位方法：
  • 基于Y坐标的文本行合并算法
  • 正则表达式的板块标题识别
  • 坐标范围的板块边界定位
数据处理逻辑：
  • 文本预处理消除格式差异
  • 同义词映射处理键名变体
  • 正则表达式精确匹配金额
  • 总计校验确保数据准确性
质量控制机制：
  • 多步骤数据验证
  • 异常情况日志记录
  • 总计与子字段对比校验
