## 经验总结

### 1. OCR置信度阈值的选择

**权衡：**
- **高阈值 (0.5+)**: 准确率高，但可能漏识别模糊文字
- **低阈值 (0.3)**: 召回率高，可识别更多文字，但可能有误识别

**最佳实践：**
- 对于财务报表等重要数据，优先选择**低阈值（0.3）**以避免漏识别
- 在数据提取阶段使用**正则表达式和规则引擎**过滤误识别

### 2. 函数参数设计原则

**DirectKeywordExtractor的设计很好：**
```python
def __init__(self, ocr_engine: OCREngine = None):
    if ocr_engine is None:
        # 使用专门优化的OCR配置
        self.ocr_engine = OCREngine(confidence_threshold=0.3)
```

**优点：**
- 默认行为最优（None时使用低阈值）
- 允许外部传入自定义OCR引擎（灵活性）
- 明确了内部需要低阈值的设计意图

**教训：**
- ❌ 不要随意传入默认参数的实例
- ✅ 理解组件的默认行为和设计意图
- ✅ 当组件有特殊要求时，让其自己创建依赖

### 3. 调试技巧

**有效的调试流程：**
1. **可视化标注** → 确认文字在图片中存在
2. **文本块列表** → 确认文字是否被OCR识别
3. **置信度分析** → 确认是否被过滤
4. **代码逻辑跟踪** → 找到过滤点
